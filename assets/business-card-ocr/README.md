# On-device business-card OCR

Pinned official npm distributions: tesseract.js 6.0.1, tesseract.js-core 6.0.0, @tesseract.js-data/kor and /eng 1.0.0 (4.0.0_best_int). Tesseract engine and language data use Apache-2.0 licensing. Language source: https://github.com/naptha/tessdata and https://github.com/tesseract-ocr/tessdata_best. Worker, core and models are served from this site. No card image is sent to an OCR service.
